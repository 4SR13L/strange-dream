STRANGEDREAM — site demonstrativo em HTML5, CSS3 e JavaScript

COMO EXECUTAR
1. Extraia a pasta strangedream-site.zip.
2. Abra index.html no navegador (ou use a extensão Live Server no VS Code).
3. Não é necessário instalar dependências.

ARQUIVOS
- index.html: estrutura semântica da loja.
- styles.css: estilos, componentes e breakpoints responsivos.
- app.js: busca, filtros, favoritos, modal de produto e carrinho com localStorage.
- assets/: imagens extraídas dos recursos incorporados no PDF fornecido.

FUNCIONALIDADES
- Catálogo com busca, ordenação e filtros por categoria/universo/estoque/preço.
- Favoritos persistidos no navegador.
- Carrinho com alteração de quantidades, remoção e resumo.
- Modal de detalhes do produto.
- Busca rápida por Ctrl/⌘ + K.
- Menu adaptado para telas pequenas.
- Formulário demonstrativo de boletim.

LIMITAÇÕES
Este é um front-end local demonstrativo. Não há backend, autenticação real, estoque sincronizado,
gateway de pagamento, cálculo real de frete ou integração de e-mail. Os dados de produtos e
preços são os exemplos presentes no material de referência. Ajuste-os antes de publicar.
